# 27.2 · ¿Para qué se utiliza?

> **Área:** Osciloscopio · Instrumentación y transmisión de señales  
> **Guía:** [Índice y navegación](./README.md)

Un osciloscopio es útil cuando no basta con conocer un único valor: también necesitas ver **cómo cambia** la señal.

El osciloscopio permite **observar**, **medir**, **comparar** y **diagnosticar** señales.

| Uso | Qué se analiza | Ejemplo de laboratorio |
|---|---|---|
| Visualizar formas de onda | Senoidal, cuadrada, triangular, pulsos | Identificar la señal del generador |
| Medir voltaje | Vmax, Vmin, Vpp, offset | Comprobar una señal de 4 Vpp |
| Medir tiempos | Período, ancho de pulso, retardo | Medir un ciclo de 1 ms |
| Calcular frecuencia | Relación entre frecuencia y período | Verificar una señal de 1 kHz |
| Comparar señales | Entrada y salida con CH1 y CH2 | Observar si un circuito altera la señal |
| Detectar alteraciones | Ruido, distorsión, transitorios | Investigar oscilaciones inesperadas |
| Analizar señales digitales | Niveles altos/bajos y transiciones | Observar un tren de pulsos |
| Analizar espectro, si hay FFT | Componentes de frecuencia | Comparar una senoidal y una cuadrada |

**Relación con telecomunicaciones:** permite estudiar la transmisión de información como señal física, antes y después de un circuito o medio de transmisión. La pantalla no muestra directamente “los bits”: muestra variaciones eléctricas que pueden **representar** información.

---

## Ejemplo cercano a telecomunicaciones

Imagina que se transmite información mediante pulsos eléctricos. El osciloscopio permite comprobar si los pulsos tienen niveles distinguibles y transiciones claras; para interpretar bits y protocolo, podrían requerirse otras herramientas o funciones adicionales.

## ¿Cuándo utilizar otro instrumento?

- **Multímetro:** cuando buscas una lectura eléctrica numérica sin necesidad de visualizar detalles rápidos.
- **Osciloscopio:** cuando interesa observar cambios temporales, pulsos o distorsión.
- **Analizador de espectro:** cuando lo principal es estudiar componentes de frecuencia con prestaciones específicas del instrumento.

Los instrumentos son complementarios: ninguno es mejor para todas las mediciones.
