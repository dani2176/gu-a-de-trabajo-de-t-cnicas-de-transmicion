1.1 Naturaleza de la información
📚 Información en los sistemas de comunicación

La información es aquello que se desea transmitir desde un punto hacia otro. Puede corresponder a una conversación, una fotografía, un video, un archivo, una medición de un sensor o cualquier otro tipo de dato.

En telecomunicaciones, la información no puede simplemente "viajar" por un cable o por el aire tal como la percibimos. Primero debe ser representada mediante señales que puedan transportarse por un medio físico.

El proceso general puede representarse así:

👤 INFORMACIÓN
      ↓
   DATOS
      ↓
   SEÑAL
      ↓
📡 TRANSMISIÓN
      ↓
   CANAL
      ↓
📥 RECEPCIÓN
      ↓
 INFORMACIÓN
Desarrollo del concepto

La información puede ser de diferentes naturalezas. Por ejemplo, la voz de una persona comienza como una señal acústica, mientras que una fotografía almacenada en un computador corresponde a información digital.

Un sistema de comunicación transforma la información a una representación que pueda ser transmitida.

Podemos pensar en tres niveles:

Información
    ↓
Representación de los datos
    ↓
Señal física

Por ejemplo:

Texto:
"HOLA"

        ↓

Datos digitales:
01001000 01001111 01001100 01000001

        ↓

Señal:
representación eléctrica, óptica o electromagnética

        ↓

Medio:
cable / fibra / radio
🔗 Relación con Redes

Este proceso permite comprender por qué una red no transmite literalmente "palabras" o "fotografías", sino representaciones de información que pueden convertirse en bits y posteriormente en señales.

🎯 Idea clave

La información es el contenido que queremos comunicar; la señal es la representación física que permite transportar esa información.

1.2 Bits y bytes
🔢 Bit

Un bit es la unidad básica de información digital y puede tomar uno de dos valores:

0
1

El término proviene de binary digit, o dígito binario.

NIST define un bit como un dígito binario con valor 0 o 1. [1]

Desarrollo del concepto

Los sistemas digitales utilizan dos estados porque resulta práctico distinguir entre dos condiciones, por ejemplo:

0 → ausencia / estado bajo
1 → presencia / estado alto

La interpretación física exacta depende del sistema.

Un bit por sí solo solamente permite dos posibilidades:

[
2^1=2
]

Si utilizamos 2 bits:

[
2^2=4
]

Con 3 bits:

[
2^3=8
]

Con 8 bits:

[
2^8=256
]

Bits	Combinaciones
1	2
2	4
3	8
4	16
8	256
💡 Ejemplo

Con 3 bits podemos representar:

000
001
010
011
100
101
110
111

Hay ocho combinaciones diferentes.

💾 Byte

Un byte corresponde a ocho bits.

[
\boxed{1\ byte=8\ bits}
]

NIST define un byte como una secuencia de ocho bits. [2]

Ejemplo:

10110101

corresponde a un byte.

Relación
1 bit
   ↓
0 o 1

8 bits
   ↓
1 byte
🔗 Relación con Redes

Cuando enviamos un archivo por una red:

Archivo
  ↓
Datos
  ↓
Bytes
  ↓
Bits
  ↓
Señal
  ↓
Medio de transmisión

Por eso los conceptos de bits, bytes y señales están directamente conectados.

1.3 Señal
📡 Definición

Una señal es una representación física de información que puede desplazarse desde un transmisor hasta un receptor.

Un sistema básico puede representarse así:

┌────────────┐
│ TRANSMISOR │
└─────┬──────┘
      │
      │ Señal
      ▼
┌────────────┐
│   CANAL    │
│ / MEDIO    │
└─────┬──────┘
      │
      ▼
┌────────────┐
│  RECEPTOR  │
└────────────┘
Desarrollo del concepto

La señal es importante porque permite convertir información abstracta en una forma física que pueda viajar.

Dependiendo del sistema, una señal puede transportarse mediante:

⚡ Señales eléctricas en cables.
🔦 Señales ópticas en fibra.
📡 Ondas electromagnéticas en comunicaciones inalámbricas.

Una señal puede caracterizarse mediante parámetros como:

Amplitud
Frecuencia
Fase
Ancho de banda
Potencia

Durante el trayecto puede sufrir:

📉 Atenuación
📢 Ruido
⚡ Interferencia
⏱️ Retardo
🎯 Idea clave

Una señal es el medio físico mediante el cual la información puede ser transportada.

1.4 Señal analógica y señal digital
🌊 Señal analógica

Una señal analógica puede variar continuamente y tomar diferentes valores dentro de un determinado rango.

Ejemplo:

       /¯\       /¯\
      /   \     /   \
_____/     \___/     \____

Un ejemplo típico es una señal eléctrica asociada a audio.

Desarrollo

Una señal analógica puede tomar valores intermedios.

Por ejemplo:

0 V
0,5 V
1,1 V
1,7 V
2,3 V
...

No está limitada necesariamente a solamente dos niveles.

💻 Señal digital

Una señal digital utiliza valores discretos para representar información.

Una representación sencilla sería:

      ┌───┐       ┌───┐
      │   │       │   │
──────┘   └───────┘   └────
       1       0      1

En sistemas digitales la información puede expresarse mediante bits:

101101001
Desarrollo del concepto

La señal digital no significa que "los bits viajan por el cable como números escritos".

Los bits deben convertirse en una representación física.

Por ejemplo:

101101
   ↓
Codificación
   ↓
Señal física
   ↓
Cable / fibra / radio

🎯 Idea clave

Una señal analógica varía continuamente, mientras que una representación digital utiliza estados discretos para representar información.

1.5 Dominio del tiempo
⏱️ Concepto

El dominio del tiempo permite observar cómo cambia una señal a medida que transcurre el tiempo.

Amplitud
   │
   │      /¯\       /¯\
   │     /   \     /   \
───┼────/─────\───/─────\────→ Tiempo
Desarrollo del concepto

El eje horizontal representa el tiempo y el eje vertical representa una magnitud de la señal.

Podemos estudiar:

Período.
Frecuencia.

Forma de onda.
Cambios de la señal.

Por ejemplo, si observamos una onda periódica:

1.6 Dominio de la frecuencia
📊 Concepto

El dominio de la frecuencia permite analizar qué componentes de frecuencia están presentes en una señal.

Amplitud
   │
   │       █
   │   █   █       █
   │   █   █       █
───┴───┴───┴───────┴────→ Frecuencia
       f1  f2      f3
Desarrollo del concepto

Una señal puede estar compuesta por varias frecuencias.

Por ejemplo:

Señal compleja
      ↓
┌─────┼─────┐
↓     ↓     ↓
f1    f2    f3

En un gráfico frecuencial, estas componentes pueden aparecer como picos.

Esto permite estudiar:

Frecuencias principales.
Componentes espectrales.
Ancho de banda.
Ruido.
Interferencias.
🔗 Relación con Redes

Cuando se analiza el espectro de una señal, se puede determinar qué rango de frecuencias utiliza y si existe interferencia en determinadas zonas.

1.7 Transformada de Fourier
🔬 Concepto

La Transformada de Fourier permite transformar una representación de una señal desde el dominio del tiempo hacia el dominio de la frecuencia. [3]

TIEMPO
  │
  │ Fourier
  ▼
FRECUENCIA
Desarrollo del concepto

Una señal compleja puede estar formada por una combinación de diferentes componentes de frecuencia.

Fourier permite separar conceptualmente esas componentes:

Señal compleja
     ↓
Fourier
     ↓
f1 + f2 + f3 + ...

Esto es especialmente útil porque una señal puede parecer compleja cuando se observa en el tiempo, pero revelar una estructura mucho más clara cuando se observa en frecuencia.

Aplicaciones
📻 Radio.
🎧 Audio.
📡 Telecomunicaciones.
📊 Análisis espectral.
🔊 Análisis de ruido.
📏 Análisis de ancho de banda.
Relación entre ambos dominios

La Transformada de Fourier es una herramienta fundamental del procesamiento de señales porque permite estudiar la distribución de energía o amplitud de una señal en frecuencia.
