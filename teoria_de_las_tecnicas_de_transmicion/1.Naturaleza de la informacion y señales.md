# 1. Naturaleza de la Información y Señales

## 1.1 Naturaleza de la información

### 📚 Información en los sistemas de comunicación

La información es aquello que se desea transmitir desde un punto hacia otro. Puede corresponder a una conversación, una fotografía, un video, un archivo, una medición de un sensor o cualquier otro tipo de dato.

En telecomunicaciones, la información no puede simplemente "viajar" por un cable o por el aire tal como la percibimos. Primero debe ser representada mediante señales que puedan transportarse por un medio físico.

### Proceso general de comunicación

El proceso general puede representarse de la siguiente manera:

```text
┌──────────────┐
│ INFORMACIÓN  │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│    DATOS     │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│    SEÑAL     │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ TRANSMISIÓN  │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│    CANAL     │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  RECEPCIÓN   │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ INFORMACIÓN  │
└──────────────┘
```

### Desarrollo del concepto

La información puede ser de diferentes naturalezas.

Por ejemplo:

- La voz de una persona comienza como una señal acústica.
- Una fotografía almacenada en un computador corresponde a información digital.
- Un sensor puede generar datos relacionados con temperatura, presión, movimiento u otras variables.

Un sistema de comunicación transforma la información a una representación que pueda ser transmitida.

Podemos pensar en tres niveles:

```text
┌────────────────────┐
│    Información     │
└─────────┬──────────┘
          │
          ▼
┌────────────────────┐
│ Representación de  │
│       los datos    │
└─────────┬──────────┘
          │
          ▼
┌────────────────────┐
│    Señal física    │
└────────────────────┘
```

### Ejemplo

**Texto:**

```text
HOLA
```

↓

**Datos digitales:**

```text
01001000 01001111 01001100 01000001
```

↓

**Señal:**

Representación eléctrica, óptica o electromagnética.

↓

**Medio:**

```text
Cable / Fibra / Radio
```

### 🔗 Relación con Redes

Este proceso permite comprender por qué una red no transmite literalmente "palabras" o "fotografías", sino representaciones de información que pueden convertirse en bits y posteriormente en señales.

### 🎯 Idea clave

La **información** es el contenido que queremos comunicar, mientras que la **señal** es la representación física que permite transportar esa información.

## 1.2 Bits y Bytes

### 🔢 Bit

Un bit es la unidad básica de información digital y puede tomar uno de dos valores:

```text
0
1
```

El término proviene de **binary digit**, o dígito binario.

### Desarrollo del concepto

Los sistemas digitales utilizan dos estados porque resulta práctico distinguir entre dos condiciones.

Por ejemplo:

```text
0 → Estado bajo / ausencia
1 → Estado alto / presencia
```

La interpretación física exacta depende del sistema utilizado.

Un bit por sí solo solamente permite dos posibilidades:

$$
2^1 = 2
$$

Si utilizamos 2 bits:

$$
2^2 = 4
$$

Con 3 bits:

$$
2^3 = 8
$$

Con 8 bits:

$$
2^8 = 256
$$

### Tabla de combinaciones

| Cantidad de bits | Cantidad de combinaciones |
|---:|---:|
| 1 | 2 |
| 2 | 4 |
| 3 | 8 |
| 4 | 16 |
| 8 | 256 |

### 💡 Ejemplo

Con 3 bits podemos representar las siguientes combinaciones:

```text
000
001
010
011
100
101
110
111
```

Hay un total de **ocho combinaciones diferentes**.

### 💾 Byte

Un byte corresponde a **ocho bits**.

$$
1\ byte = 8\ bits
$$

### Ejemplo

```text
10110101
```

La secuencia anterior corresponde a un byte.

### Relación entre bit y byte

```text
┌──────────────┐
│     1 bit    │
└──────┬───────┘
       │
       ▼
    0 o 1


┌──────────────┐
│    8 bits    │
└──────┬───────┘
       │
       ▼
    1 byte
```

### 🔗 Relación con Redes

Cuando enviamos un archivo por una red, la información puede seguir un proceso como el siguiente:

```text
Archivo
   ↓
Datos
   ↓
Bytes
   ↓
Bits
   ↓
Señal
   ↓
Medio de transmisión
```

Por eso, los conceptos de **bits, bytes y señales** están directamente conectados.

## 1.3 Señal

### 📡 Definición

Una señal es una representación física de información que puede desplazarse desde un transmisor hasta un receptor.

Un sistema básico puede representarse de la siguiente manera:

```text
┌─────────────┐
│ TRANSMISOR  │
└──────┬──────┘
       │
       │ Señal
       ▼
┌─────────────┐
│    CANAL    │
│  / MEDIO    │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  RECEPTOR   │
└─────────────┘
```

### Desarrollo del concepto

La señal es importante porque permite convertir información abstracta en una forma física que pueda viajar.

Dependiendo del sistema, una señal puede transportarse mediante:

- ⚡ Señales eléctricas en cables.
- 🔦 Señales ópticas en fibra.
- 📡 Ondas electromagnéticas en comunicaciones inalámbricas.

Una señal puede caracterizarse mediante diferentes parámetros, como:

- Amplitud.
- Frecuencia.
- Fase.
- Ancho de banda.
- Potencia.

Durante el trayecto, una señal puede sufrir diferentes efectos:

- 📉 Atenuación.
- 📢 Ruido.
- ⚡ Interferencia.
- ⏱️ Retardo.

### 🎯 Idea clave

Una señal es el **medio físico mediante el cual la información puede ser transportada**.

---

## 1.4 Señal analógica y señal digital

### 🌊 Señal analógica

Una señal analógica puede variar continuamente y tomar diferentes valores dentro de un determinado rango.

### Ejemplo

Una señal de audio capturada por un micrófono es un ejemplo de una señal analógica.

### Representación

```text
Amplitud
   │
   │       ╭──╮          ╭──╮
   │      ╱    ╲        ╱    ╲
   │     ╱      ╲      ╱      ╲
   │────╯        ╰────╯        ╰────
   │
   └────────────────────────────────── Tiempo
```

### Características

- Tiene variación continua.
- Puede tomar muchos valores de amplitud.
- Puede verse afectada por ruido e interferencias.
- Puede representarse mediante una onda continua.

### Desarrollo

Una señal analógica puede tomar valores intermedios.

Por ejemplo:

```text
0 V
0,5 V
1,1 V
1,7 V
2,3 V
...
```

Por lo tanto, no está limitada necesariamente a solamente dos niveles.

---

### 💻 Señal digital

Una señal digital utiliza valores discretos para representar información.

En los sistemas digitales es común utilizar bits representados mediante `0` y `1`.

### Representación

```text
Amplitud
   │
 1 │     ┌──────┐          ┌──────┐
   │     │      │          │      │
   │     │      │          │      │
 0 │─────┘      └──────────┘      └──────
   │
   └────────────────────────────────────── Tiempo
```

### Ejemplo

Una representación digital de información puede ser:

```text
101101001
```

### Desarrollo

La señal digital no significa que "los bits viajan por el cable como números escritos".

Los bits deben convertirse en una representación física.

Por ejemplo:

```text
101101
   ↓
Codificación
   ↓
Señal física
   ↓
Cable / Fibra / Radio
```

### Tabla comparativa

| Característica | Analógica | Digital |
|---|---|---|
| **Valores** | Continuos | Discretos |
| **Representación** | Onda continua | Estados o símbolos |
| **Ejemplo** | Audio analógico | Datos digitales |
| **Procesamiento** | Analógico o mixto | Digital o mixto |
| **Relación con bits** | No necesariamente digital | Puede representar bits |

### 🎯 Idea clave

Una señal analógica **varía continuamente**, mientras que una representación digital utiliza **estados discretos** para representar información.

## 1.5 Dominio del tiempo

### ⏱️ Concepto

El dominio del tiempo permite observar cómo cambia una señal a medida que transcurre el tiempo.

### Representación

```text
Amplitud
   │
   │       ╭──╮          ╭──╮
   │      ╱    ╲        ╱    ╲
   │     ╱      ╲      ╱      ╲
   │────╯        ╰────╯        ╰────
   │
   └────────────────────────────────── Tiempo
```

El eje horizontal representa el **tiempo**, mientras que el eje vertical representa una **magnitud de la señal**.

### Podemos estudiar

- Amplitud.
- Período.
- Frecuencia.
- Duración.
- Forma de onda.
- Cambios de la señal.

### Ejemplo

Si observamos una onda periódica:

```text
          1 ciclo
       <──────────>

          ╭──╮
         ╱    ╲
────────╯      ╰────────
```

podemos determinar cuánto tarda en repetirse.

Ese tiempo corresponde al **período**:

$$
T
$$

### 🔗 Relación

Si conocemos el período podemos obtener la frecuencia:

$$
f = \frac{1}{T}
$$

Por lo tanto:

```text
Dominio del tiempo
        ↓
Observamos el período
        ↓
Calculamos la frecuencia
```

## 1.6 Dominio de la frecuencia

### 📊 Concepto

El dominio de la frecuencia permite analizar qué componentes de frecuencia están presentes en una señal.

A diferencia del dominio del tiempo, donde se observa principalmente cómo cambia una señal a medida que transcurre el tiempo, en el dominio de la frecuencia se analiza cómo se distribuye la información entre diferentes frecuencias.

### Representación

```text
Amplitud
   │
   │          │
   │     │    │       │
   │     │    │       │
   │     │    │       │
   └─────┴────┴───────┴────────── Frecuencia
         f1   f2      f3
```

### Desarrollo del concepto

Una señal puede estar compuesta por varias frecuencias.

Por ejemplo:

```text
Señal compleja
      │
      ├──────── f1
      ├──────── f2
      └──────── f3
```

En un gráfico frecuencial, estas componentes pueden aparecer como picos.

### Podemos estudiar

- Frecuencias principales.
- Componentes espectrales.
- Ancho de banda.
- Ruido.
- Interferencias.

### 🔗 Relación con Redes

Cuando se analiza el espectro de una señal, se puede determinar qué rango de frecuencias utiliza y si existe interferencia en determinadas zonas.

### 🎯 Idea clave

El dominio de la frecuencia permite estudiar **qué frecuencias forman parte de una señal** y cómo se distribuye su contenido espectral.

---

## 1.7 Transformada de Fourier

### 🔬 Concepto

La Transformada de Fourier permite transformar una representación de una señal desde el **dominio del tiempo** hacia el **dominio de la frecuencia**.

### Representación

```text
┌──────────────────────┐
│  Señal en el tiempo  │
└──────────┬───────────┘
           │
           │ Transformada
           │ de Fourier
           ▼
┌──────────────────────┐
│ Señal en frecuencia  │
└──────────────────────┘
```

### Desarrollo del concepto

Una señal compleja puede estar formada por una combinación de diferentes componentes de frecuencia.

La Transformada de Fourier permite separar conceptualmente esas componentes.

Por ejemplo:

```text
Señal compleja
      │
      │ Transformada
      │ de Fourier
      ▼
┌─────┬─────┬─────┐
│ f1  │ f2  │ f3  │
└─────┴─────┴─────┘
```

También puede representarse como:

```text
Señal compleja
      ↓
Fourier
      ↓
f1 + f2 + f3 + ...
```

Esto es especialmente útil porque una señal puede parecer compleja cuando se observa en el tiempo, pero revelar una estructura mucho más clara cuando se observa en frecuencia.

### Aplicaciones

La Transformada de Fourier se utiliza en diferentes áreas, por ejemplo:

- 📻 Radio.
- 🎧 Audio.
- 📡 Telecomunicaciones.
- 📊 Análisis espectral.
- 🔊 Análisis de ruido.
- 📏 Análisis de ancho de banda.

### Relación entre ambos dominios

```text
┌──────────────────┐
│ Dominio temporal │
└────────┬─────────┘
         │
         │ Fourier
         ▼
┌────────────────────┐
│ Dominio frecuencial│
└────────────────────┘
```

### Importancia

La Transformada de Fourier es una herramienta fundamental del procesamiento de señales porque permite estudiar la distribución de energía o amplitud de una señal en frecuencia.

### 🎯 Idea clave

La Transformada de Fourier permite pasar del **dominio del tiempo** al **dominio de la frecuencia**, facilitando el análisis de las diferentes componentes que forman una señal.
