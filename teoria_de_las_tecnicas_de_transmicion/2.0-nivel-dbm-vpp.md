# 2.0 Nivel de señal, potencia, dB, dBm y Vpp

## 🟢 Para comenzar

Una vez que sabemos leer una señal, necesitamos aprender a describir qué tan grande es y cómo expresar su nivel. En Telecomunicaciones aparecen varias formas de hacerlo: voltaje, potencia, Vpp, dB y dBm.

No son sinónimos. Cada una describe una magnitud o una relación diferente, por lo que es fundamental saber qué mide cada unidad antes de realizar cálculos.

El **nivel de señal** describe qué tan grande es una señal respecto de una referencia. La amplitud es una de las formas más comunes de observar ese nivel.

```text
          ▲ máximo
          │
       /¯¯¯¯¯\
      /       \
─────/─────────\─────
```

## 🔎 Para profundizar

Dependiendo del sistema pueden utilizarse distintas magnitudes para hablar del nivel: voltaje, potencia, valor pico, valor pico a pico, valor eficaz o unidades logarítmicas como dB y dBm.

Es importante no mezclar estas magnitudes.

```text
V      → tensión
Vpp    → tensión pico a pico
dBm    → potencia respecto de 1 mW
dB     → relación logarítmica entre niveles
```

### 🧮 Ejemplo

Para una señal con:

\[
V_{max}=4V,
\quad V_{min}=-4V
\]

se obtiene:

\[
V_{pp}=8V
\]

### 🛰️ Ejemplo aplicado

En una medición con osciloscopio se puede observar directamente el voltaje y la forma de onda. En sistemas de RF es frecuente utilizar unidades logarítmicas para expresar niveles de potencia.

### 🎯 Idea clave

> Antes de hablar de potencia o decibelios hay que identificar qué magnitud se está midiendo: voltaje, potencia, nivel pico u otra.
## 🧭 ¿Cómo se puede expresar el nivel?

Dependiendo del instrumento y de la aplicación, el nivel puede describirse con diferentes magnitudes.

```text
Voltaje → V, mV, Vpp
Potencia → W, mW, dBm
Relación → dB
```

### 🧠 ¿Por qué existen varias unidades?

Porque voltaje y potencia no son la misma magnitud física.

Un técnico puede medir en un osciloscopio una señal de `2 Vpp`, mientras que en una etapa de RF puede hablar de una potencia recibida de `-70 dBm`.

### 🔗 Relación con la medición

Siempre debemos preguntar primero:

> ¿Qué magnitud está midiendo el problema?

Esto evita aplicar una fórmula de potencia a un dato de voltaje o viceversa.

### 🎯 Para recordar

> Antes de calcular hay que identificar si estamos trabajando con voltaje, potencia o una relación entre niveles.


**dBm** es una unidad logarítmica de potencia referenciada a `1 mW`. Por definición:

\[
0dBm=1mW
\]

La relación puede expresarse como:

\[
P(dBm)=10\log_{10}\left(\frac{P(mW)}{1mW}\right)
\]

Keysight documenta dBm como una medida de potencia referida a 1 mW.[4]

## 🔎 Para profundizar

La escala logarítmica permite trabajar cómodamente con potencias que pueden variar varios órdenes de magnitud.

### 📊 Valores útiles

| Potencia | dBm |
|---:|---:|
| 1 mW | 0 dBm |
| 10 mW | 10 dBm |
| 100 mW | 20 dBm |
| 1 W = 1000 mW | 30 dBm |

### 🧮 Ejemplo básico

Si:

\[
P=10mW
\]

entonces:

\[
P(dBm)=10\log_{10}(10)=10dBm
\]

### 🧮 Ejemplo inverso

Para convertir de dBm a mW:

\[
P(mW)=10^{P(dBm)/10}
\]

Si tenemos `20 dBm`:

\[
P=10^{20/10}=100mW
\]

### 💡 Interpretación

```text
0 dBm  → 1 mW
10 dBm → 10 mW
20 dBm → 100 mW
30 dBm → 1000 mW
```

Cada aumento de 10 dB representa un factor 10 en potencia.

### ⚠️ Diferencia entre dB y dBm

```text
dB  → relación entre niveles
 dBm → potencia absoluta referenciada a 1 mW
```

### 🛰️ Ejemplo aplicado

En un enlace inalámbrico puede ser necesario expresar la potencia transmitida o recibida en dBm para comparar niveles de señal y pérdidas del enlace.

### 🎯 Idea clave

> dBm expresa potencia utilizando 1 mW como referencia; no es una unidad de frecuencia ni de voltaje.
## 🧮 Ejemplos de conversión dBm

### De mW a dBm

Si:

\[
P=100mW
\]

entonces:

\[
P(dBm)=10\log_{10}(100)=20dBm
\]

### De dBm a mW

Si:

\[
P=30dBm
\]

entonces:

\[
P(mW)=10^{30/10}=1000mW=1W
\]

### 📊 Regla rápida

```text
+10 dB → ×10 en potencia
-10 dB → ÷10 en potencia
+3 dB  → aproximadamente ×2 en potencia
-3 dB  → aproximadamente ÷2 en potencia
```

Estas aproximaciones son útiles para comprender rápidamente presupuestos de enlace, aunque para cálculos precisos debe utilizarse la fórmula exacta.

### 🛰️ Ejemplo aplicado

Un transmisor entrega `20 dBm` y un tramo provoca `6 dB` de pérdida:

\[
20dBm-6dB=14dBm
\]

Esto permite seguir el nivel de potencia a lo largo del enlace.

### ⚠️ Error frecuente

No se debe “sumar mW y dBm” directamente. Primero hay que convertir a una unidad compatible.


El **voltaje pico a pico (Vpp)** representa la diferencia total entre el máximo y el mínimo de una señal.

\[
V_{pp}=V_{max}-V_{min}
\]

## 🔎 Para profundizar

En una señal que oscila alrededor de `0 V`, el valor máximo puede ser positivo y el mínimo negativo.

```text
          Vmax
            ▲
            │
          /¯¯¯\
         /     \
────────/───────\────────
       /         \
      /           \
     ▼
   Vmin

<-------- Vpp -------->
```

### 🧮 Ejemplo básico

Si:

\[
V_{max}=5V
\]

\[
V_{min}=-5V
\]

entonces:

\[
V_{pp}=5-(-5)=10V
\]

### 🧮 Ejemplo adicional

Si una señal oscila entre `1 V` y `4 V`:

\[
V_{pp}=4-1=3V
\]

No debemos restar solamente el valor máximo; siempre se consideran ambos extremos.

### 🔗 Relación con amplitud

Para una sinusoidal centrada en cero, si el valor de pico es `Vp`, entonces:

\[
V_{pp}=2V_p
\]

Pero esta relación no debe utilizarse sin comprobar primero que la señal está centrada de esa forma.

### 🛰️ Ejemplo aplicado

En el laboratorio, un osciloscopio puede mostrar Vpp directamente. Este parámetro es útil para describir el nivel de una forma de onda.

### 🎯 Idea clave

> Vpp mide toda la excursión de la señal, desde el valor mínimo hasta el valor máximo.
## 🧮 Relación entre Vp y Vpp

Para una sinusoidal centrada en cero:

\[
V_{pp}=2V_p
\]

Por lo tanto, si:

\[
V_p=2V
\]

entonces:

\[
V_{pp}=4V
\]

### ⚠️ Condición

Esta relación supone una señal centrada en cero. Si existe un offset DC, debemos obtener Vmax y Vmin directamente.

### 🧮 Ejemplo con offset

Supongamos:

\[
V_{max}=7V
\]

\[
V_{min}=3V
\]

Entonces:

\[
V_{pp}=7-3=4V
\]

La señal podría tener un componente DC de `5 V` aproximadamente y una excursión de `±2 V` alrededor de él, dependiendo de su forma.

### 🎯 Para recordar

> Vpp mide la diferencia entre los dos extremos de la señal; no depende de que el mínimo sea negativo.


El **ancho de banda (BW)** representa la extensión de un rango de frecuencias utilizado o disponible por una señal o sistema.

Para un rango definido entre una frecuencia mínima y una máxima:

\[
BW=f_{max}-f_{min}
\]

## 🧠 Diferencias que no se deben confundir

```text
dB   → expresa una relación entre dos niveles

dBm  → expresa potencia absoluta tomando 1 mW como referencia

V    → tensión
Vpp  → diferencia entre el máximo y mínimo de tensión

Hz   → frecuencia
bit/s → cantidad de bits por segundo
```

La unidad utilizada debe corresponder con la magnitud que se está midiendo. No es correcto utilizar dBm como si fuera una frecuencia ni confundir Vpp con potencia.
