# 1.7 Dominio de la frecuencia, espectro y Fourier

## 🟢 Para comenzar

Después de aprender a observar una señal en el tiempo, podemos cambiar de perspectiva y preguntarnos: **¿qué frecuencias contiene esa señal?** Esa pregunta nos lleva al dominio de la frecuencia y al concepto de espectro.

Una vez entendido el espectro, la Transformada de Fourier se puede introducir de manera natural como una herramienta que permite pasar entre la descripción temporal y la frecuencial.

En lugar de preguntar “¿cómo cambia la señal con el tiempo?”, ahora preguntamos:

> “¿Qué frecuencias forman la señal?”

Una señal que parece compleja en el tiempo puede contener varias componentes más simples en frecuencia.

```text
Señal compleja
      ↓
┌─────┼─────┐
↓     ↓     ↓
f1    f2    f3
```

### 📐 Rango de frecuencias

Si una señal ocupa desde `fmin` hasta `fmax`, podemos definir un ancho de banda:

\[
BW=f_{max}-f_{min}
\]

Este concepto se desarrollará en la sección de parámetros técnicos.

### 📢 Ruido en frecuencia

El ruido también puede aparecer en el espectro. El análisis frecuencial puede mostrar regiones donde existe energía no deseada.

### 🛰️ Ejemplo aplicado

Un analizador de espectro permite observar distintas componentes frecuenciales. Esto es útil para investigar interferencias, revisar bandas ocupadas y analizar transmisiones de radiofrecuencia.

### 🧠 Relación con Fourier

El dominio de la frecuencia se vuelve especialmente útil cuando contamos con una herramienta capaz de transformar una señal del tiempo a la frecuencia. Esa herramienta es la Transformada de Fourier.

### 🎯 Idea clave

> El dominio del tiempo muestra cómo cambia la señal; el dominio de la frecuencia muestra qué componentes frecuenciales contiene.
## 🧠 Antes de interpretar un espectro

Un espectro no representa “tiempo”. Representa **frecuencia**.

```text
Eje X → Hz
Eje Y → nivel de la componente
```

Si aparece un pico en `1 kHz`, significa que existe una componente de esa frecuencia con un determinado nivel.

### 🧮 Ejemplo

Supongamos que una señal contiene principalmente:

```text
500 Hz
1 kHz
2 kHz
```

Su espectro podría representarse conceptualmente:

```text
Amplitud
   │       █
   │   █   █      █
   │   █   █      █
───┴───┴───┴──────┴────→ Hz
      500 1000   2000
```

### 🔗 Relación con ancho de banda

Si la señal tiene componentes importantes entre `500 Hz` y `2 kHz`, puede estudiarse un rango aproximado mediante:

\[
BW=2000-500=1500Hz
\]

El ancho de banda exacto depende de cómo se definan los límites del sistema o señal.

### 🎯 Para recordar

> El dominio de frecuencia responde a la pregunta “¿qué frecuencias hay en la señal y cómo se distribuyen?”.


La **Transformada de Fourier** es una herramienta matemática que permite expresar una señal en términos de sus componentes de frecuencia. En una aplicación típica, convierte una representación del dominio del tiempo a una representación del dominio de la frecuencia.[3]

```text
⏱️ Dominio del tiempo
        │
        │ Transformada de Fourier
        ▼
📊 Dominio de la frecuencia
```

## 🔎 Para profundizar

Una señal compleja puede entenderse como la combinación de diferentes componentes sinusoidales o frecuenciales. Fourier permite analizar esas componentes.

```text
Señal compleja
      ↓
     Fourier
      ↓
┌─────┬─────┬─────┐
│ f1  │ f2  │ f3  │
└─────┴─────┴─────┘
```

Por ejemplo, una señal puede contener una componente de 100 Hz y otra de 300 Hz. En el dominio del tiempo podríamos observar una forma de onda resultante de ambas. En el dominio de la frecuencia podríamos observar dos componentes principales.

### 🧮 Ejemplo conceptual

```text
Señal A → 100 Hz
Señal B → 300 Hz
        ↓
   combinación
        ↓
señal compleja
        ↓
     Fourier
        ↓
100 Hz + 300 Hz
```

### 🛰️ Aplicaciones

Fourier se relaciona con:

- 🎧 procesamiento de audio;
- 📻 radiofrecuencia;
- 📡 telecomunicaciones;
- 📊 análisis de espectros;
- 🔊 estudio de ruido;
- 📏 análisis del ancho de banda.

### ⚠️ Fourier no es lo mismo que FFT

La Transformada de Fourier es la transformación matemática. La **FFT (Fast Fourier Transform)** es un algoritmo eficiente para calcular una Transformada de Fourier Discreta.[3]

### 🔗 Relación con la asignatura

Fourier conecta dos formas fundamentales de estudiar una señal:

```text
Tiempo
  ↕
Fourier
  ↕
Frecuencia
```

Esta conexión será importante cuando estudiemos ancho de banda, modulación y espectro.

### 🎯 Idea clave

> Fourier permite cambiar de una visión temporal de la señal a una visión frecuencial para entender de qué componentes está formada.
## 🧠 ¿Por qué necesitamos Fourier?

Cuando una señal es compleja, verla solamente en el tiempo puede dificultar identificar qué componentes la forman.

Fourier nos permite cambiar de perspectiva:

```text
“¿Cómo cambia?”
      ↓
     Fourier
      ↓
“¿Qué frecuencias contiene?”
```

### 🧮 Ejemplo conceptual

Supongamos que tenemos dos senoidales:

\[
f_1=100Hz
\]

\[
f_2=500Hz
\]

Al sumarlas obtenemos una señal compleja.

Fourier permite observar las componentes de `100 Hz` y `500 Hz` en el espectro.

### 🔎 Diferencia entre FT, DFT y FFT

- **FT**: Transformada de Fourier como concepto matemático.
- **DFT**: versión discreta utilizada para datos muestreados.
- **FFT**: algoritmo eficiente para calcular la DFT.

### 🛰️ Ejemplo aplicado

En un sistema de audio se puede analizar el espectro para observar componentes tonales y ruido. En RF se puede utilizar para investigar bandas ocupadas e interferencias.

### ⚠️ Error frecuente

Fourier no “crea” frecuencias nuevas. Es una herramienta de análisis y representación de las componentes presentes en la señal, de acuerdo con el modelo utilizado.
