# 3.0 Banda base y codificación

## 🟢 Para comenzar

Ahora que conocemos las señales y sus parámetros, podemos estudiar cómo se prepara una señal para ser transmitida. Dos conceptos básicos son la **banda base** y la **codificación**.

La banda base describe cómo se encuentra ubicada la señal en frecuencia, mientras que la codificación describe cómo representamos los datos para transmitirlos e interpretarlos correctamente.

Una señal en **banda base** ocupa su rango original de frecuencias y no ha sido desplazada a otra banda mediante una portadora.

```text
Datos
 ↓
Codificación
 ↓
Señal de banda base
 ↓
Medio
```

## 🔎 Para profundizar

El concepto de banda base describe principalmente la posición espectral de una señal. No significa simplemente “señal digital”. Una señal digital puede estar en banda base, pero lo digital y la banda base son clasificaciones diferentes.

```text
DIGITAL / ANALÓGICA
→ cómo se representa la información

BANDA BASE / PASABANDA
→ cómo está ubicada la señal en frecuencia
```

### 🛰️ Ejemplo

Una transmisión de datos que utiliza una forma de onda de banda base envía la señal alrededor de sus frecuencias originales, sin trasladarla mediante una portadora de RF.

### 🔗 Relación con modulación

En una transmisión pasabanda podemos partir de una señal de información y utilizar una portadora:

```text
Señal de información
        ↓
     Modulador
        ↓
Señal pasabanda
```

La modulación será la encargada de realizar ese desplazamiento o de representar la información sobre la portadora.

### 🎯 Idea clave

> Banda base describe una señal en su rango original de frecuencias; modulación puede utilizar una portadora para trasladar la información a otra banda.
## 🔎 Banda base y pasabanda

Conviene introducir esta comparación porque evita muchas confusiones:

```text
BANDA BASE
→ señal alrededor de sus frecuencias originales

PASABANDA
→ señal trasladada a una región de frecuencias determinada
```

La modulación es uno de los mecanismos que puede utilizarse para llevar una señal de información a una frecuencia portadora.

### 🛰️ Ejemplo

```text
Audio
 ↓
Señal de información
 ↓
Modulador
 ↓
Portadora RF
 ↓
Antena
```

### ⚠️ Error frecuente

No decir “banda base = digital” como si fueran sinónimos. Se refieren a características diferentes.


La **codificación** transforma los datos en una representación adecuada para su transmisión o procesamiento.

```text
Datos
10110010
   ↓
Codificación
   ↓
Señal
```

## 🔎 Para profundizar

Los bits no recorren físicamente un cable como números escritos. Deben convertirse en una señal eléctrica, óptica o electromagnética. El esquema de codificación determina cómo representar esos bits mediante niveles, transiciones o símbolos.

### 📝 Ejemplo conceptual

```text
Bits:
1 0 1 1 0

        ↓

Codificador
        ↓

Forma de onda
```

### 🔗 Codificación vs modulación

Estos conceptos están relacionados, pero no son exactamente lo mismo:

```text
Codificación
→ decide cómo representar los datos.

Modulación
→ utiliza una señal portadora y modifica una característica para transportar información.
```

En algunos sistemas los conceptos aparecen uno después del otro.

```text
Datos
 ↓
Codificación
 ↓
Símbolos
 ↓
Modulación
 ↓
Canal
```

### 🛰️ Ejemplo aplicado

En una red de datos, la interfaz física debe transformar la secuencia de bits en una señal que pueda transmitirse por el medio correspondiente.

### 🎯 Idea clave

> Codificar es convertir los datos a una representación apropiada; modular es utilizar una portadora y modificarla para transportar información.
## 🧭 ¿Qué problema resuelve la codificación?

El transmisor necesita una representación de los bits que el sistema físico pueda enviar y el receptor pueda reconocer.

```text
Bits
 ↓
Esquema de codificación
 ↓
Forma de señal
 ↓
Canal
 ↓
Decodificación
 ↓
Bits
```

### 🧠 Ejemplo conceptual

Si el sistema utiliza una codificación por niveles, puede establecer una correspondencia entre estados y niveles.

```text
0 → nivel A
1 → nivel B
```

La tecnología real puede utilizar reglas mucho más complejas.

### 🔗 Relación con sincronización

Algunas codificaciones facilitan que el receptor detecte transiciones y mantenga el sincronismo.

### 🎯 Para recordar

> La codificación establece cómo se representan los datos para que el sistema de comunicación pueda transportarlos y recuperarlos.


La **modulación** consiste en utilizar una señal portadora y modificar una de sus características de acuerdo con la información que queremos transmitir.

```text
Información
     │
     ▼
┌────────────┐
│ MODULADOR  │
└─────┬──────┘
      ▼
Señal modulada
      ▼
   📡 CANAL
```
