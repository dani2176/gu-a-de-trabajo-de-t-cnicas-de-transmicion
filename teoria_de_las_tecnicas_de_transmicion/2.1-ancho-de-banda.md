# 2.1 Ancho de banda

## 🟢 Para comenzar

Una señal no utiliza todas las frecuencias posibles. Normalmente ocupa un rango determinado. Ese rango se relaciona con el concepto de **ancho de banda**.

El ancho de banda será importante más adelante porque aparece tanto en el análisis del espectro como en la capacidad de canal de Shannon.

```text
fmin                                      fmax
 │                                         │
 ▼                                         ▼
─|=========================================|─
                 BW
```

### 🧮 Ejemplo básico

Si una señal ocupa desde `2 MHz` hasta `10 MHz`:

\[
BW=10MHz-2MHz=8MHz
\]

### 🧠 Ejemplo avanzado

En telecomunicaciones, ancho de banda también puede referirse al rango efectivo de frecuencias que un sistema permite pasar o al ancho espectral de una señal. Por eso siempre conviene indicar el contexto.

Por ejemplo:

```text
fmin = 2 MHz
fmax = 10 MHz

BW = 8 MHz
```

### 🔗 Relación con Fourier

Fourier permite observar las componentes frecuenciales de una señal. A partir de ese espectro podemos estudiar qué rango de frecuencias ocupa.

```text
Señal
 ↓
Fourier
 ↓
Espectro
 ↓
frecuencias presentes
 ↓
BW
```

### 🔗 Relación con Shannon

El ancho de banda aparece en:

\[
C=B\log_2(1+SNR)
\]

Por lo tanto, también influye en la capacidad teórica de un canal.

### ⚠️ No confundir

```text
BW ≠ bit rate
```

El ancho de banda se expresa en Hz, mientras que el bit rate se expresa en bit/s.

### 🎯 Idea clave

> El ancho de banda describe un rango de frecuencias; el bit rate describe una cantidad de bits por segundo.
## 🧭 Cómo encontrar el ancho de banda

Siempre debemos identificar primero las dos frecuencias límite.

```text
fmin → inicio del rango
fmax → final del rango
```

Después:

\[
BW=f_{max}-f_{min}
\]

### 🧮 Ejemplo

Una señal ocupa desde `88 MHz` hasta `108 MHz`:

\[
BW=108-88=20MHz
\]

### 🔎 El ancho de banda no es “velocidad de Internet”

Esta confusión es muy común.

```text
BW → rango de frecuencias
bit rate → bits por segundo
```

Los dos pueden estar relacionados, pero no son equivalentes.

### 🔗 Relación con Fourier

Fourier permite observar el espectro y, a partir de este, analizar qué rango de frecuencias ocupa una señal.

### 🔗 Relación con Shannon

Un mayor ancho de banda puede aumentar la capacidad teórica si las demás condiciones se mantienen iguales.


La **velocidad de propagación** representa la rapidez con que una señal se desplaza por un medio.

\[
v=\frac{d}{t}
\]

donde:

- `v` = velocidad de propagación;
- `d` = distancia;
- `t` = tiempo.
