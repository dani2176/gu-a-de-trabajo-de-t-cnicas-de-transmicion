# 🔗 20. Cuadro comparativo de transmisión

## 🔗 Serie y paralelo

| Característica | Serie | Paralelo |
|---|---|---|
| **Bits** | Uno después de otro | Varios simultáneamente |
| **Líneas** | Menos | Más |
| **Cableado** | Menor | Mayor |
| **Organización** | Secuencial | Simultánea |

---

## ⏱️ Síncrona y asíncrona

| Característica | Síncrona | Asíncrona |
|---|---|---|
| **Tiempo** | Coordinado | Sin reloj compartido continuamente |
| **Datos** | Flujo coordinado | Unidades delimitadas |
| **Estructura** | Referencia temporal | Inicio / datos / parada |

### 🎯 Forma fácil de recordarlo

```text
SERIE
1 → 0 → 1 → 1

PARALELO
1 ─────►
0 ─────►
1 ─────►
1 ─────►
```

```text
SÍNCRONA
⏱️ Tiempo coordinado

ASÍNCRONA
📦 Inicio + datos + parada
```
