# 4.1 Nyquist-Shannon, muestreo, aliasing y conversión A/D

## 🟢 Para comenzar

Cuando una señal analógica debe convertirse en datos digitales, necesitamos tomar muestras. Nyquist-Shannon indica qué tan rápido debemos muestrear para poder representar correctamente una señal limitada en banda.

A partir de ahí aparecen muestreo, aliasing, filtros antialiasing y las etapas del ADC: muestreo, cuantización y codificación.

El número:

\[
2f_{max}
\]

corresponde al límite de Nyquist para una señal cuya frecuencia máxima es `fmax`.

### 🧮 Ejemplo

Si:

\[
f_{max}=20kHz
\]

entonces:

\[
f_s>2(20kHz)
\]

\[
f_s>40kHz
\]

Una frecuencia de muestreo de `44,1 kHz` supera ese límite para una señal cuyo contenido de interés llega a 20 kHz.

### ⚠️ Condición ideal vs práctica

En la teoría ideal se trabaja con una señal limitada en banda y condiciones de reconstrucción bien definidas. En la práctica se utilizan filtros y márgenes para evitar que componentes cercanas al límite provoquen problemas.

### 🔗 Relación con ADC

Nyquist es el concepto que determina la frecuencia de muestreo que debemos considerar antes de realizar la conversión analógico-digital.

```text
Señal analógica
      ↓
fmax conocida
      ↓
Nyquist
      ↓
Elegir fs
      ↓
ADC
```

### 🎯 Idea clave

> Nyquist-Shannon indica cuánto debemos muestrear para conservar correctamente la información frecuencial de una señal limitada en banda.
## 🧠 ¿Por qué “dos veces”?

Una señal cuya frecuencia máxima es `fmax` tiene un período asociado:

\[
T=\frac1{f_{max}}
\]

El límite de muestreo se relaciona con obtener suficientes muestras para conservar la información frecuencial.

### 🧮 Ejemplo

Si:

\[
f_{max}=10kHz
\]

entonces:

\[
f_s>20kHz
\]

Una frecuencia de `25 kHz` supera ese límite en el modelo ideal.

### 🔗 Relación con aliasing

```text
fs adecuada → representación correcta
fs insuficiente → posibilidad de aliasing
```

### ⚠️ Error frecuente

No confundir “frecuencia de la señal” con “frecuencia de muestreo”. Son variables diferentes.


El **muestreo** consiste en tomar valores de una señal continua en determinados instantes.

```text
Señal continua
      /¯\       /¯\
     /   \     /   \
____/     \___/     \____

Muestras
    ●   ●   ●   ●   ●
```

## 🔎 Para profundizar

Una señal analógica tiene un valor para cada instante de tiempo. Un sistema digital trabaja con una secuencia finita de observaciones, por lo que toma muestras.

Si se toman `48.000` muestras por segundo, la frecuencia de muestreo es:

\[
f_s=48kHz
\]

### 🧮 Ejemplo

Con `48 kHz`:

```text
48.000 muestras cada segundo
```

Si además cada muestra utiliza 16 bits:

\[
48.000\times16=768.000bit/s
\]

Este resultado se obtiene antes de considerar compresión u otras sobrecargas.

### 🔗 Relación con Nyquist

El muestreo debe elegirse después de conocer el contenido de frecuencia que queremos conservar.

```text
Frecuencia máxima
       ↓
Nyquist
       ↓
Frecuencia de muestreo
```

### 🎯 Idea clave

> Muestrear es tomar “fotografías” de una señal en instantes concretos; la cantidad de fotografías por segundo es la frecuencia de muestreo.
## 🧮 Ejemplo visual

Una señal continua puede representarse como:

```text
     /¯\      /¯\
    /   \    /   \
___/     \__/     \___
```

Al muestrearla obtenemos:

```text
    ●   ●   ●   ●   ●
```

Cada punto representa una observación de la señal.

### 🔎 Muestreo alto vs bajo

```text
Muestreo bajo:
●      ●      ●      ●

Muestreo alto:
● ● ● ● ● ● ● ● ● ●
```

El segundo caso ofrece una representación temporal más densa, pero aumenta la cantidad de muestras por segundo y, sin compresión, puede aumentar el flujo de datos.

### 🎯 Para recordar

> Muestrear no significa convertir inmediatamente la muestra a bits; la cuantización y codificación ocurren después.


El **aliasing** ocurre cuando una señal se muestrea de manera insuficiente y las componentes de frecuencia quedan representadas incorrectamente.[7]

```text
Señal original
/\/\/\/\/\/\/\/\/\

Muestras insuficientes
•     •     •     •

Resultado incorrecto
~~~~\________/~~~~
```

## 🔎 Para profundizar

Cuando una componente está por encima de la frecuencia de Nyquist, puede aparecer en la señal muestreada como una frecuencia diferente y más baja.

National Instruments muestra un ejemplo de una señal de 800 kHz muestreada a 1 MS/s que aparece como un alias de 200 kHz.[7]

### 🧮 Ejemplo conceptual

Si:

\[
f_s=1MHz
\]

la frecuencia de Nyquist es:

\[
f_N=500kHz
\]

Una componente de `800 kHz` está por encima de ese límite y puede aparecer como un alias:

\[
f_a=|1MHz-800kHz|=200kHz
\]

### 🎛️ Filtro antialiasing

Para reducir este problema se coloca un filtro, normalmente paso bajo, antes del muestreo y del ADC.

```text
🌊 Señal de entrada
        ↓
🎛️ Filtro antialiasing
        ↓
🔄 Muestreo
        ↓
💻 ADC
```

El filtro limita las frecuencias que podrían provocar aliasing.[10]

### ✅ Cómo reducir el problema

```text
✔ Limitar la señal antes del muestreo
✔ Elegir una frecuencia de muestreo adecuada
✔ Utilizar filtros apropiados
```

### 🎯 Idea clave

> El aliasing es un error de representación provocado por un muestreo insuficiente; el filtro antialiasing ayuda a impedir que frecuencias problemáticas lleguen al muestreador.
## 🧮 Ejemplo numérico de aliasing

Supongamos:

\[
f_s=1MHz
\]

Entonces:

\[
f_N=500kHz
\]

Si la entrada contiene:

\[
f_{in}=800kHz
\]

esa componente está por encima del límite.

En un ejemplo sencillo puede aparecer como:

\[
f_a=|1.000-800|=200kHz
\]

### 🧠 ¿Qué significa?

El sistema podría registrar una señal de `200 kHz` cuando realmente estaba presente una componente de `800 kHz`.

### 🎛️ Filtro antialiasing

Para impedir que esa componente entre al proceso:

```text
Entrada
  ↓
Filtro paso bajo
  ↓
Muestreador
  ↓
ADC
```

### 🎯 Para recordar

> El aliasing no es simplemente “ruido”; es una representación incorrecta de frecuencia causada por el proceso de muestreo.


Un **ADC (Analog-to-Digital Converter)** transforma una señal analógica en una representación digital.

```text
🌊 Señal analógica
        ↓
     🔄 ADC
        ↓
💻 Datos digitales
```

Para estudiarlo pedagógicamente se divide en tres etapas principales:

```text
1️⃣ Muestreo
      ↓
2️⃣ Cuantización
      ↓
3️⃣ Codificación
```

## 🔎 Para profundizar

### 1. Muestreo

Se toma el valor de la señal en instantes determinados.

### 2. Cuantización

Cada muestra se aproxima a uno de un número finito de niveles.

### 3. Codificación

El nivel cuantizado se representa mediante un código binario.

### 🛰️ Ejemplo de voz

```text
🗣️ Voz
 ↓
🎤 Micrófono
 ↓
🌊 Señal analógica
 ↓
🎛️ Filtro
 ↓
🔄 Muestreo
 ↓
🎚️ Cuantización
 ↓
🔢 Codificación
 ↓
💻 Bits
```

National Instruments utiliza el ejemplo de la voz capturada por un teléfono como señal analógica que debe convertirse a digital para transmitirla.[7]

### 🔗 Relación con Nyquist

Antes del ADC debemos conocer la frecuencia máxima de interés para elegir la frecuencia de muestreo.

### 🔗 Relación con bits

La cantidad de bits del ADC determina el número de niveles disponibles para la cuantización.

### 🎯 Idea clave

> Un ADC no “convierte de golpe” una onda en bits: primero toma muestras, después las cuantiza y finalmente las representa mediante códigos digitales.
## 🧭 La secuencia que no se debe confundir

El orden pedagógico correcto es:

```text
1. Filtrar cuando sea necesario
2. Muestrear
3. Cuantizar
4. Codificar
```

Cada etapa responde una pregunta distinta:

```text
Muestreo   → ¿en qué instantes tomo valores?
Cuantizar  → ¿a qué nivel disponible asigno cada muestra?
Codificar  → ¿cómo represento ese nivel digitalmente?
```

### 🛰️ Ejemplo de voz

```text
🗣️ Voz
 ↓
🎤 Micrófono
 ↓
🎛️ Filtro
 ↓
🔄 Muestreo
 ↓
🎚️ Cuantización
 ↓
🔢 Codificación
 ↓
📡 Transmisión
```

### ⚠️ Error frecuente

No decir que “Nyquist es una etapa del ADC”. Nyquist es un criterio teórico que ayuda a seleccionar la frecuencia de muestreo adecuada.


La **cuantización** consiste en asignar cada muestra a uno de un número finito de niveles.

```text
Nivel 4 ─────────────
Nivel 3 ─────────────
Nivel 2 ─────●───────
Nivel 1 ─────────────
```

## 🔎 Para profundizar

La señal original puede tener valores continuos, pero el ADC posee una cantidad limitada de niveles. Por eso cada muestra debe aproximarse a uno de esos niveles.

```text
Valor real
   ↓
aproximación
   ↓
nivel disponible
```

La diferencia entre el valor real y el nivel asignado es el **error de cuantización**.

### 🧮 Ejemplo

Supongamos que un sistema tiene niveles:

```text
0 V
1 V
2 V
3 V
4 V
```

Si la muestra vale `2,4 V`, debe aproximarse a uno de los niveles disponibles, por ejemplo `2 V` o `3 V`, según la regla del convertidor.

### 🔎 Resolución y cuantización

Aumentar la cantidad de niveles permite hacer una aproximación más fina.

```text
Pocos niveles:
|----|----|----|----|

Muchos niveles:
|-|-|-|-|-|-|-|-|-|-|
```

### 🎯 Idea clave

> Cuantizar significa convertir una muestra continua en uno de un conjunto finito de niveles disponibles.
## 🧮 Ejemplo paso a paso

Imaginemos un ADC con cuatro niveles:

```text
0 → 0 V
1 → 1 V
2 → 2 V
3 → 3 V
```

Si una muestra vale `2,7 V`, el sistema debe asignarla al nivel disponible correspondiente según su regla de cuantización.

Si se asigna a `3 V`, aparece un error de:

\[
3-2,7=0,3V
\]

### 🔎 ¿Qué cambia al aumentar la resolución?

Con más niveles, la separación entre niveles es menor:

```text
Pocos niveles
|---------|---------|---------|

Muchos niveles
|--|--|--|--|--|--|--|--|--|
```

Esto permite aproximaciones más finas.

### 🎯 Para recordar

> Cuantización convierte una cantidad continua de valores posibles en una cantidad finita de niveles.


Después de cuantizar una muestra, el sistema puede representar el nivel elegido mediante un código binario.

Ejemplo con 8 niveles:

| Nivel | Código |
|---:|---|
| 0 | 000 |
| 1 | 001 |
| 2 | 010 |
| 3 | 011 |
| 4 | 100 |
| 5 | 101 |
| 6 | 110 |
| 7 | 111 |

## 🔎 Para profundizar

Supongamos que una muestra fue asignada al nivel 5.

```text
Muestra
  ↓
Nivel 5
  ↓
101
```

Ahora el resultado puede almacenarse o procesarse como datos digitales.

### 🧩 Secuencia completa

```text
Señal analógica
      ↓
Muestra
      ↓
Nivel cuantizado
      ↓
Código binario
```

### 🔗 Relación con bits

Si tenemos 8 niveles:

\[
2^3=8
\]

necesitamos 3 bits para representar todos los niveles.

### 🎯 Idea clave

> La codificación es la etapa donde el nivel cuantizado recibe una representación digital mediante bits.
## 🧩 De nivel a bits

Supongamos que el ADC tiene 8 niveles.

Como:

\[
8=2^3
\]

necesitamos tres bits para identificar los niveles.

```text
Nivel 0 → 000
Nivel 1 → 001
Nivel 2 → 010
...
Nivel 7 → 111
```

### 🔎 Relación con la información

La señal analógica fue transformada progresivamente:

```text
Valor continuo
      ↓
Muestra
      ↓
Nivel discreto
      ↓
Código binario
```

### 🎯 Para recordar

> La codificación A/D es el último paso de la cadena de conversión que convierte el nivel cuantizado en una representación digital.


La resolución de un ADC indica cuántos niveles puede utilizar para representar el rango de entrada. Si el ADC tiene `n` bits:

\[
N=2^n
\]

donde `N` es la cantidad de niveles.

## 🔎 Para profundizar

### Ejemplos

```text
3 bits  → 2³  = 8 niveles
8 bits  → 2⁸  = 256 niveles
10 bits → 2¹⁰ = 1024 niveles
12 bits → 2¹² = 4096 niveles
16 bits → 2¹⁶ = 65536 niveles
```

### 🧮 Ejemplo de resolución de voltaje

Supongamos un ADC ideal de 8 bits con rango de `0 a 5 V`.

Hay:

\[
2^8=256
\]

niveles.

Una aproximación del tamaño de paso es:

\[
\Delta V\approx\frac{5V}{256}
\]

\[
\Delta V\approx0,0195V
\]

es decir, aproximadamente `19,5 mV` por nivel en este modelo simplificado.

### 💡 Interpretación

```text
Más bits
   ↓
Más niveles
   ↓
Paso más pequeño
   ↓
Mayor resolución
```

### ⚠️ Importante

Una mayor resolución no elimina automáticamente todo el ruido. También existen limitaciones de ruido, exactitud, referencia, estabilidad y otras características del ADC real.

### 🎯 Idea clave

> Más bits permiten disponer de más niveles de cuantización y representar cambios más pequeños de la señal, dentro de las demás limitaciones del sistema.
## 🧮 Ejemplo comparativo

Supongamos que tenemos el mismo rango de 0 a 5 V.

### ADC de 3 bits

\[
2^3=8
\]

Hay 8 niveles.

### ADC de 8 bits

\[
2^8=256
\]

Hay 256 niveles.

Por lo tanto, el segundo puede dividir el rango en pasos mucho más pequeños.

### 🔎 Relación con error de cuantización

En general, una mayor resolución reduce el tamaño del paso de cuantización, aunque la precisión y el ruido total de un ADC real dependen de más factores que solo la cantidad nominal de bits.

### 🎯 Para recordar

> Los bits del ADC determinan cuántos niveles tiene disponible para cuantizar el rango de entrada.


Cuando una señal se digitaliza, la frecuencia de muestreo y la cantidad de bits por muestra determinan una tasa de datos ideal.

\[
R_b=f_s\times n
\]

donde:

- `Rb` = bit rate;
- `fs` = muestras por segundo;
- `n` = bits por muestra.

## 🧮 Ejemplo básico

Si:

\[
f_s=48kHz
\]

\[
n=16bits/muestra
\]

entonces:

\[
R_b=48.000\times16
\]

\[
\boxed{R_b=768.000bit/s}
\]

## 🔎 Para profundizar

Este cálculo supone que todas las muestras se transmiten con el mismo número de bits y que no se considera compresión ni sobrecarga adicional.

### 🧮 Ejemplo avanzado

Si duplicamos la frecuencia de muestreo manteniendo `16 bits/muestra`:

\[
88,2kHz\times16=1.411.200bit/s
\]

El bit rate se duplica.

### ⚠️ No confundir

```text
Frecuencia de muestreo → muestras/s
Bits por muestra       → profundidad digital
Bit rate               → bits/s
Ancho de banda         → Hz
```

Estos conceptos están relacionados pero no son iguales.

### 🎯 Idea clave

> En una digitalización sin compresión, el bit rate depende directamente de cuántas muestras se toman por segundo y de cuántos bits se usan en cada muestra.
## 🧮 Ejemplo comparativo completo

Supongamos un sistema de audio con:

\[
f_s=48kHz
\]

\[
n=16bits/muestra
\]

Entonces:

\[
R_b=48.000\times16=768.000bit/s
\]

Si se duplica la frecuencia de muestreo:

\[
96.000\times16=1.536.000bit/s
\]

Por lo tanto, el flujo de datos sin compresión se duplicó.

### ⚠️ ¿Se duplicó automáticamente el ancho de banda del canal?

No necesariamente. El ancho de banda de la señal o canal depende del sistema físico y de cómo se represente y module ese flujo digital.

### 🎯 Para recordar

> Aumentar la frecuencia de muestreo aumenta directamente la cantidad de muestras por segundo; si los bits por muestra permanecen constantes, también aumenta el bit rate bruto.
