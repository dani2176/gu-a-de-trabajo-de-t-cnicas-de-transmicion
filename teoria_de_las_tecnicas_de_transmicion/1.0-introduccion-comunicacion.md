# 1.0 Introducción a la comunicación y la información

## 🟢 Para comenzar

Antes de estudiar fórmulas o tipos de señales, necesitamos entender qué significa comunicar información. En Telecomunicaciones, el objetivo final de un sistema es llevar un mensaje desde un origen hasta un destino utilizando una representación física que pueda viajar por un medio.

Esta sección construye esa base: primero se diferencia información, datos y señal; luego se observa el camino que sigue la información dentro de un sistema de comunicación. Esta base será necesaria para comprender los bits, las señales y los parámetros que aparecen en las siguientes secciones.

La **información** es aquello que una persona, dispositivo o sistema desea comunicar. Puede ser una conversación, una fotografía, una medición, una página web, un video o una instrucción enviada a un equipo de red.

En telecomunicaciones, la información no puede desplazarse por sí sola desde un punto de origen hacia un destino. Para poder transportarla, primero debe convertirse en una representación que pueda viajar a través de un medio.

```text
📚 INFORMACIÓN
      ↓
💻 DATOS
      ↓
📡 SEÑAL
      ↓
🌐 MEDIO DE TRANSMISIÓN
      ↓
📥 RECEPCIÓN
      ↓
📚 INFORMACIÓN
```

## 🔎 Para profundizar

La información puede presentarse de maneras muy diferentes. La voz comienza como una onda acústica, una fotografía puede almacenarse como datos digitales y un sensor puede producir valores numéricos relacionados con temperatura, presión, movimiento o luz.

El sistema de comunicación debe transformar esa información a una forma compatible con el canal. Por eso es útil distinguir tres niveles:

```text
┌────────────────────┐
│  Información       │ ← qué queremos comunicar
└─────────┬──────────┘
          ↓
┌────────────────────┐
│  Datos             │ ← cómo se representa
└─────────┬──────────┘
          ↓
┌────────────────────┐
│  Señal física      │ ← cómo puede viajar
└────────────────────┘
```

Por ejemplo, si queremos enviar el texto `HOLA`, un computador puede representarlo mediante códigos digitales, convertirlos en bits y posteriormente representar esos bits mediante una señal eléctrica, óptica o electromagnética.

```text
HOLA
 ↓
Código de los caracteres
 ↓
Bits
 ↓
Símbolos / forma de señal
 ↓
Cable, fibra o radio
```

### 📝 Ejemplo básico

Supongamos que dos computadores desean intercambiar un archivo.

```text
💻 PC A
  │
  │ Archivo
  ▼
🔢 Datos y bits
  │
  ▼
📡 Señal
  │
  ▼
🔌 Cable
  │
  ▼
💻 PC B
```

El archivo es la **información**, los bits forman parte de su **representación digital** y la señal es la forma física utilizada para transportarlos.

### 🛰️ Ejemplo aplicado

En una llamada telefónica, la voz del usuario se convierte en una señal eléctrica mediante el micrófono. En un sistema digital, esa señal puede ser muestreada, cuantizada y codificada antes de transmitirse como datos.

### 🔗 Relación con la asignatura

Este concepto es la base de todo lo que sigue. Para comprender bits, señales, modulación, muestreo y capacidad de canal primero hay que entender la diferencia entre **lo que se quiere comunicar** y **la forma física utilizada para transportarlo**.

### 🎯 Idea clave

> La información es el contenido que queremos comunicar; una señal es la representación física que permite transportar ese contenido.
## 🧭 Cómo encaja este concepto en Telecomunicaciones

Cuando estudiamos telecomunicaciones conviene separar tres ideas:

```text
📚 ¿Qué quiero enviar?
        ↓
💻 ¿Cómo represento lo que quiero enviar?
        ↓
📡 ¿Cómo lo convierto en una señal que pueda viajar?
```

La primera pregunta corresponde a la **información**. La segunda corresponde a la representación de los datos. La tercera corresponde a la señal y al sistema físico de transmisión.

### 📝 Ejemplo paso a paso: enviar una fotografía

1. 📷 La fotografía es la información que queremos comunicar.
2. 💻 El computador la representa como datos digitales.
3. 🔢 Esos datos pueden organizarse en bits y bytes.
4. 🧩 El sistema realiza el procesamiento y codificación necesarios.
5. 📡 Los datos se representan mediante una señal física.
6. 🌐 La señal atraviesa el medio.
7. 📥 El receptor procesa la señal y reconstruye los datos.
8. 📷 El usuario vuelve a obtener la fotografía.

### ⚠️ Error frecuente

No se debe decir que **información, datos y señal son exactamente lo mismo**. Son conceptos relacionados, pero representan niveles diferentes del proceso.

### 🎯 Para recordar

```text
Información → contenido
Datos        → representación
Señal        → forma física de transporte
```


Un **bit** es la unidad básica de información digital. Puede tomar uno de dos valores: `0` o `1`.[1]

```text
0  ← un estado
1  ← otro estado
```
