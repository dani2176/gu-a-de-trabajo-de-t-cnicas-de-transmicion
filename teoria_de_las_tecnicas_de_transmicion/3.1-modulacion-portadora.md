# 3.1 Modulación y señal portadora

## 🟢 Para comenzar

La modulación aparece cuando queremos utilizar una señal portadora para transportar información. La idea central es modificar una característica de la portadora de acuerdo con la información.

Antes de estudiar AM y FM conviene comprender qué es una portadora, qué significa modular y qué proceso realiza el receptor para recuperar la información.

Las características principales que pueden modificarse son:

```text
📈 Amplitud → AM
🔄 Frecuencia → FM
📐 Fase → PM
```

En sistemas digitales aparecen técnicas como:

```text
ASK → amplitud
FSK → frecuencia
PSK → fase
QAM → amplitud + fase
```

En el receptor se realiza la demodulación para recuperar la información.

```text
Señal modulada
      ↓
Demodulador
      ↓
Información
```

### 🧠 ¿Por qué utilizar una portadora?

Una señal de información puede tener un rango de frecuencias que no sea conveniente para el medio o para la antena utilizada. La modulación permite trasladar la información a otra región del espectro.

### 🛰️ Ejemplo aplicado

Una emisora de radio puede tomar una señal de audio y utilizarla para modificar una portadora. El receptor realiza el proceso inverso para recuperar el audio.

### 🔗 Relación con frecuencia y ancho de banda

La modulación cambia la posición o características espectrales de la señal. Por eso los conceptos de frecuencia y ancho de banda son fundamentales para comprenderla.

### 🎯 Idea clave

> Modular es utilizar una portadora y modificar alguna de sus características para transportar información.
## 🧩 ¿Qué elementos intervienen?

Una modulación típica puede entenderse mediante:

```text
Información
      +
Portadora
      ↓
   Modulador
      ↓
Señal modulada
```

La portadora proporciona una referencia de frecuencia que puede ser adecuada para el canal y la antena.

### 🔎 Parámetros que pueden modificarse

```text
AM → amplitud
FM → frecuencia
PM → fase
```

En digital se utilizan variantes como ASK, FSK, PSK y QAM.

### 🛰️ Ejemplo

Una emisora de radio no envía simplemente “la voz” por el aire. Utiliza un sistema de modulación para incorporar la información de audio a una señal de radiofrecuencia.

### 🎯 Para recordar

> Modulación significa transportar información modificando una portadora de acuerdo con la información.


**AM (Amplitude Modulation)** significa modulación de amplitud. En AM, la información modifica principalmente la **amplitud de la portadora**.[6]
