# 1.6 Dominio del tiempo

## 🟢 Para comenzar

El dominio del tiempo es la forma más directa de observar una señal: vemos cómo cambia a medida que pasa el tiempo. Para interpretarlo correctamente necesitamos utilizar los conceptos de amplitud, período y frecuencia que acabamos de estudiar.

Por eso esta sección no introduce esos conceptos desde cero, sino que enseña a utilizarlos juntos para leer una forma de onda.

En una gráfica típica:

- el eje horizontal representa el tiempo;
- el eje vertical representa una magnitud, como voltaje o amplitud.

Una vez que conocemos los parámetros de la sección anterior podemos leer la gráfica con mayor facilidad.

### 🔗 Lectura en secuencia

```text
SEÑAL
  ↓
Amplitud
  ↓
Máximo y mínimo
  ↓
Vpp
  ↓
Período
  ↓
Frecuencia
```

### 🧮 Ejemplo guiado

Supongamos que una señal completa un ciclo cada 5 ms.

Primero convertimos:

\[
5ms=0,005s
\]

Después:

\[
f=\frac{1}{T}
\]

\[
f=\frac{1}{0,005}=200Hz
\]

### 🛰️ Ejemplo aplicado

Un osciloscopio muestra una señal en el dominio del tiempo. El técnico puede observar si existe una distorsión, un cambio en amplitud, un período inesperado o una perturbación.

### 💡 ¿Por qué es útil?

El dominio del tiempo es especialmente útil cuando queremos saber **qué está haciendo la señal en cada instante**. Por ejemplo, puede ayudarnos a observar pulsos, transiciones, ruido o la duración de un evento.

### 🎯 Idea clave

> En el dominio del tiempo analizamos la evolución temporal de la señal y usamos parámetros como amplitud, período y frecuencia para describirla.
## 📖 Lectura pedagógica de una gráfica temporal

Una gráfica en el dominio del tiempo debe leerse de izquierda a derecha porque representa la evolución de la señal.

```text
        tiempo →
   ──────────────────────►

        amplitud ↑
```

Si la gráfica muestra una onda periódica, podemos identificar:

```text
máximo → mínimo → máximo
       ↕
    1 ciclo
```

### 🧮 Ejemplo más desarrollado

Una señal completa 5 ciclos durante `0,1 s`.

La frecuencia puede calcularse como:

\[
f=\frac{5}{0,1}
\]

\[
f=50Hz
\]

Entonces el período será:

\[
T=\frac1{50}=0,02s
\]

### 🔗 Qué nos permite hacer este análisis

Desde una gráfica temporal podemos obtener información sobre:

- duración;
- amplitud;
- periodicidad;
- frecuencia;
- pulsos;
- transiciones;
- perturbaciones.

### 🛰️ Aplicación

Un osciloscopio muestra precisamente este tipo de representación y permite observar el comportamiento temporal de señales eléctricas.

### 🎯 Para recordar

> Primero se lee la señal en el tiempo y después se calculan los parámetros que permiten describirla.


El **dominio de la frecuencia** permite analizar qué frecuencias están presentes en una señal y con qué nivel relativo aparecen.
