# 1.1 Información, datos, bits y bytes

## 🟢 Para comenzar

Cuando una red transmite información digital, esa información termina representándose como bits. Para estudiar la transmisión es necesario saber qué es un bit, cómo se agrupan los bits en bytes y cómo varias combinaciones de bits pueden representar diferentes estados o símbolos.

Este paso es importante porque más adelante los bits se relacionarán con codificación, modulación, símbolos, baud y velocidad de transmisión.

Los sistemas digitales utilizan una representación binaria porque permite distinguir dos estados de manera sencilla. La forma física de esos estados depende del sistema: pueden corresponder a diferentes niveles eléctricos, estados lógicos, cambios de fase, pulsos ópticos u otras representaciones.

Con `n` bits se pueden formar:

\[
N=2^n
\]

combinaciones diferentes.

| Bits | Combinaciones |
|---:|---:|
| 1 | 2 |
| 2 | 4 |
| 3 | 8 |
| 4 | 16 |
| 8 | 256 |
| 16 | 65.536 |

### 🧮 Ejemplo básico

Con 3 bits:

```text
000
001
010
011
100
101
110
111
```

Existen:

\[
2^3=8
\]

combinaciones.

### 💾 Byte

Un **byte** corresponde a una secuencia de ocho bits.[2]

\[
1\ byte=8\ bits
\]

Ejemplo:

```text
10110101
```

es una secuencia de ocho bits y puede tratarse como un byte.

### 🧠 ¿Por qué importa en Redes?

Una red transporta información digital como una secuencia de bits. Los bytes permiten agrupar esos bits en unidades utilizadas habitualmente por los computadores.

```text
📄 Archivo
   ↓
💾 Bytes
   ↓
🔢 Bits
   ↓
📡 Señal
   ↓
🌐 Canal
```

### 🧮 Ejemplo avanzado

Un archivo de `1 MB` contiene una cantidad de datos que puede expresarse en bytes y, posteriormente, en bits. En redes, el tamaño del archivo se combina con el **bit rate** para estimar cuánto tiempo puede tardar una transferencia ideal.

Si se transfieren 10 Mbit mediante un enlace de 100 Mbit/s:

\[
t=\frac{10\ Mbit}{100\ Mbit/s}=0,1s
\]

El resultado es una aproximación ideal y no incluye encabezados, pérdidas, retransmisiones ni otras sobrecargas.

### 🔗 Relación con otros conceptos

Los bits serán fundamentales para comprender **codificación, símbolos, baud, bit rate y modulación digital**.

### 🎯 Idea clave

> Los bits representan información digital; los bytes son agrupaciones de ocho bits y ambos forman parte de los datos que posteriormente deben convertirse en señales para ser transmitidos.
## 🧮 Ejemplo ampliado: combinaciones binarias

Si una señal o sistema digital necesita representar cuatro estados distintos, ¿cuántos bits hacen falta?

Buscamos el número `n` que cumpla:

\[
2^n\geq4
\]

Con dos bits:

\[
2^2=4
\]

Por lo tanto, necesitamos al menos 2 bits.

### 🔎 Más ejemplos

```text
2 estados  → 1 bit
4 estados  → 2 bits
8 estados  → 3 bits
16 estados → 4 bits
32 estados → 5 bits
```

Esta misma idea será utilizada más adelante al estudiar **símbolos y modulación digital**.

## 🔗 Bit, símbolo y modulación

Un símbolo puede representar un estado de una señal. Si existen muchos estados, un símbolo puede transportar más de un bit.

Por ejemplo, con 16 estados:

\[
\log_2(16)=4
\]

Por lo tanto, un símbolo puede representar 4 bits en un esquema ideal.

### ⚠️ Error frecuente

**Un bit no es lo mismo que un símbolo.** Un bit es una unidad de información; un símbolo es una unidad de señalización.

### 🎯 Para recordar

```text
Bits → información binaria
Símbolos → estados utilizados para transmitirla
```


Una **señal** es una representación física de información que puede propagarse desde un transmisor hasta un receptor.

```text
📤 TRANSMISOR
     │
     │ señal
     ▼
🌐 CANAL / MEDIO
     │
     │ señal recibida
     ▼
📥 RECEPTOR
```
