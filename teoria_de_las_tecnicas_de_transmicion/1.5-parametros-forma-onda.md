# 1.5 Amplitud, valor pico, Vpp, período y frecuencia

## 🟢 Para comenzar

Para poder leer una gráfica de una señal primero debemos aprender a reconocer sus características básicas. Las más importantes son la amplitud, los valores máximo y mínimo, el valor pico a pico, el período y la frecuencia.

Estos conceptos deben estudiarse juntos porque están directamente relacionados: el período permite obtener la frecuencia y los valores máximo y mínimo permiten obtener Vpp.

La amplitud describe el nivel instantáneo de una señal respecto de una referencia.

En una señal sinusoidal puede utilizarse el valor de pico para describir cuánto se aleja del valor de referencia.

## ⬆️ Valor máximo y ⬇️ valor mínimo

Son los extremos alcanzados por la señal en el intervalo observado.

## ↕️ Voltaje pico a pico

La diferencia entre máximo y mínimo se expresa como:

\[
V_{pp}=V_{max}-V_{min}
\]

### 🧮 Ejemplo

Si:

\[
V_{max}=5V
\]

\[
V_{min}=-5V
\]

entonces:

\[
V_{pp}=5-(-5)=10V
\]

## ⏱️ Período

El período `T` es el tiempo que tarda una señal periódica en repetir un ciclo completo.

```text
       1 ciclo
     <--------->
       /¯\
      /   \
─────/─────\─────
```

## 🔄 Frecuencia

La frecuencia `f` indica cuántos ciclos se realizan por segundo.

\[
f=\frac{1}{T}
\]

### 🧮 Ejemplo

Si:

\[
T=0,01s
\]

entonces:

\[
f=\frac{1}{0,01}=100Hz
\]

La señal realiza 100 ciclos por segundo.

## 🔎 Para profundizar

Estos parámetros están relacionados, pero no son equivalentes.

```text
Amplitud → nivel
Vpp      → distancia entre máximo y mínimo
Período  → tiempo de un ciclo
Frecuencia → ciclos por segundo
```

Una señal puede tener la misma frecuencia y diferente amplitud:

```text
Señal A:   /¯\_/¯\_/¯\_

Señal B:  /¯¯¯\___/¯¯¯\___
```

También puede tener la misma amplitud y diferente frecuencia:

```text
Frecuencia baja:  /¯\_______/¯\

Frecuencia alta:  /¯\_/¯\_/¯\_/¯\
```

### 🎯 Idea clave

> Para interpretar una señal primero debemos aprender a distinguir su nivel, cuánto tarda en repetirse y cuántas veces se repite por segundo.
## 🧭 Cómo leer una forma de onda sin memorizar

Cuando recibamos una gráfica, podemos analizarla en este orden:

### 1️⃣ Buscar el eje vertical

Preguntamos:

> ¿Qué magnitud está mostrando?

Puede ser voltaje, amplitud u otra magnitud.

### 2️⃣ Buscar el eje horizontal

Preguntamos:

> ¿Representa tiempo?

Si es así, estamos en el dominio temporal.

### 3️⃣ Identificar el máximo y mínimo

Esto permite obtener valores de pico y Vpp.

### 4️⃣ Buscar un ciclo completo

Esto permite obtener el período.

### 5️⃣ Calcular la frecuencia

Una vez conocido `T`:

\[
f=\frac1T
\]

### 🧮 Ejercicio guiado

Supongamos que una onda tiene:

- máximo = `+3 V`;
- mínimo = `-3 V`;
- período = `2 ms`.

Primero:

\[
V_{pp}=3-(-3)=6V
\]

Después convertimos:

\[
2ms=0,002s
\]

Finalmente:

\[
f=\frac1{0,002}=500Hz
\]

### 🎯 Resultado

```text
Vpp = 6 V
f   = 500 Hz
```

### ⚠️ Error frecuente

Confundir `2 ms` con `2 s`. Las unidades deben convertirse antes de aplicar la fórmula.


El **dominio del tiempo** describe una señal observando cómo cambia una magnitud de esa señal a medida que pasa el tiempo.

```text
Amplitud
   │
   │       /¯\        /¯\
   │      /   \      /   \
───┼─────/─────\────/─────\──→ Tiempo
```
