# 🌐 14. Ejemplo integrado: transmisión de datos

Supongamos que un computador envía información a un servidor.

## 🔄 Proceso

```text
💻 COMPUTADOR
      ↓
📄 Información
      ↓
🔢 Bits
      ↓
🧩 Codificación
      ↓
📡 Señal
      ↓
🔌 / 🔦 / 📶 Medio
      ↓
🌐 Canal
      ↓
📥 Receptor
      ↓
🔢 Bits
      ↓
📄 Información
```

---

## 🧩 Parámetros involucrados

Durante el proceso pueden aparecer:

```text
🔄 Frecuencia
📏 Ancho de banda
📉 Atenuación
📢 Ruido
📶 SNR
🚀 Velocidad de propagación
🔢 Bit rate
🚦 Baud
```

---

## 🎯 Idea clave

La transmisión de datos combina la información digital, los bits, la codificación, la señal física y el medio de transmisión para permitir que los datos lleguen desde el origen hasta el destino.
