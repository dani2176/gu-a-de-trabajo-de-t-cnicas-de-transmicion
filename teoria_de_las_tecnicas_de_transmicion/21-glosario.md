# 📖 Glosario de Transmisión de Señales

Este glosario sirve como apoyo rápido después de estudiar las 20 secciones. Las definiciones no sustituyen la explicación de cada capítulo: sirven para recordar el significado de cada término.

| Término | Significado |
|---|---|
| Información | Contenido que se desea comunicar. |
| Datos | Representación organizada de la información. |
| Bit | Unidad básica de información digital: 0 o 1. |
| Byte | Grupo de ocho bits. |
| Señal | Representación física que permite transportar información. |
| Onda | Perturbación que se propaga y puede transportar energía e información. |
| Amplitud | Nivel instantáneo de una señal respecto de una referencia. |
| Pico | Valor máximo o mínimo de una señal respecto de una referencia, según el contexto. |
| Vpp | Diferencia entre el valor máximo y mínimo. |
| Período | Tiempo que tarda un ciclo en repetirse. |
| Frecuencia | Cantidad de ciclos por segundo. |
| Fase | Desplazamiento relativo de una señal dentro de su ciclo. |
| Longitud de onda | Distancia espacial asociada a un ciclo. |
| Ancho de banda | Rango de frecuencias ocupado o disponible. |
| Atenuación | Pérdida de nivel o potencia durante la transmisión. |
| Ruido | Perturbación no deseada. |
| SNR | Relación señal a ruido. |
| C/N | Relación portadora a ruido. |
| dB | Medida logarítmica de una relación entre niveles. |
| dBm | Potencia expresada respecto de 1 mW. |
| Bit rate | Bits por segundo. |
| Baud | Símbolos por segundo. |
| Portadora | Señal utilizada para transportar información mediante modulación. |
| Banda base | Señal en su banda de frecuencias original. |
| Modulación | Proceso de modificar una portadora para transportar información. |
| AM | Modulación de amplitud. |
| FM | Modulación de frecuencia. |
| ASK | Modulación digital por desplazamiento de amplitud. |
| FSK | Modulación digital por desplazamiento de frecuencia. |
| PSK | Modulación digital por desplazamiento de fase. |
| QAM | Modulación que utiliza amplitud y fase. |
| Shannon | Modelo de capacidad teórica de canal con ruido. |
| Nyquist-Shannon | Teorema que establece la condición de muestreo para una señal limitada en banda. |
| Aliasing | Representación incorrecta de frecuencias causada por muestreo insuficiente. |
| ADC | Convertidor analógico-digital. |
| Cuantización | Aproximación de cada muestra a un nivel disponible. |
| Codificación | Representación de datos mediante una regla o esquema para su transmisión. |
| Transmisión serie | Envío secuencial de bits. |
| Transmisión paralela | Envío simultáneo de bits por varias líneas. |
| Síncrona | Transmisión con referencia temporal coordinada. |
| Asíncrona | Transmisión que no mantiene un reloj compartido continuamente y puede usar bits de inicio/parada. |
