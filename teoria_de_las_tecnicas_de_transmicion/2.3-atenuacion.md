# 2.3 Atenuación y presupuesto de potencia

## 🟢 Para comenzar

Cuando una señal sale del transmisor no necesariamente llega al receptor con el mismo nivel. Una parte de su potencia puede perderse durante el recorrido. A esa pérdida se le llama **atenuación**.

La atenuación es fundamental en redes y telecomunicaciones porque permite entender por qué la distancia, el cableado y los componentes afectan al nivel recibido.

La atenuación puede estar relacionada con la distancia, las características del cable, conectores, componentes y propiedades del medio.

### 🧮 Ejemplo básico

Si:

\[
P_{entrada}=100mW
\]

\[
P_{salida}=10mW
\]

entonces:

\[
A=10\log_{10}(10)=10dB
\]

### 🛰️ Ejemplo aplicado a un enlace

Supongamos que un transmisor entrega `0 dBm` y el enlace presenta `10 dB` de pérdida.

En un modelo ideal de suma de pérdidas en dB:

\[
P_{recibida}=0dBm-10dB=-10dBm
\]

Este tipo de cálculo es muy utilizado para presupuestos de enlace.

### 🔗 Relación con el medio

```text
Mayor distancia
       ↓
Más oportunidades de pérdida
       ↓
Mayor atenuación
       ↓
Menor nivel recibido
```

### 🎯 Idea clave

> La atenuación describe cuánto se debilita una señal durante su recorrido.
## 🧮 Presupuesto de potencia

En telecomunicaciones es frecuente sumar ganancias y pérdidas en dB.

Ejemplo:

```text
Potencia TX = 10 dBm
Cable       = -3 dB
Conector    = -1 dB
Otro tramo  = -2 dB
```

Entonces:

\[
P_{RX}=10-3-1-2
\]

\[
\boxed{P_{RX}=4dBm}
\]

### 🔎 ¿Qué nos dice el resultado?

El receptor recibe un nivel menor que el transmitido debido a las pérdidas.

Si además existe una sensibilidad mínima del receptor, se puede comparar el nivel recibido con esa sensibilidad para saber si existe margen suficiente.

### 🎯 Para recordar

```text
Ganancias → suman
Pérdidas   → restan
```

cuando todas están expresadas en dB y se trabaja con un presupuesto de enlace.


El **ruido** es una perturbación no deseada que se mezcla con la señal que queremos recibir.

```text
Señal útil
────────────────────

Ruido
~~~~ ~~~~ ~~~ ~~~~

Señal recibida
────~──≈────~──≈───
```
