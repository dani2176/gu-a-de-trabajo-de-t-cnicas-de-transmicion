# 📚 17. Cuadro general de conceptos

| Concepto | Significado | Unidad |
|---|---|---|
| **Bit** | Unidad digital básica | 0 / 1 |
| **Byte** | Ocho bits | 8 bits |
| **Bit rate** | Bits transmitidos por segundo | bit/s |
| **Baud** | Símbolos por segundo | baud |
| **Período** | Tiempo de un ciclo | s |
| **Frecuencia** | Ciclos por segundo | Hz |
| **Amplitud** | Nivel de la señal | V / otras |
| **Vpp** | Diferencia máximo-mínimo | V |
| **dBm** | Potencia respecto a 1 mW | dBm |
| **BW** | Rango de frecuencias | Hz |
| **Velocidad de propagación** | Rapidez de desplazamiento | m/s |
| **Atenuación** | Pérdida de señal | dB |
| **Ruido** | Perturbación no deseada | — |
| **SNR** | Señal respecto al ruido | dB |
| **C/N** | Portadora respecto al ruido | dB |
| **AM** | Modulación de amplitud | — |
| **FM** | Modulación de frecuencia | — |
| **ADC** | Conversor analógico-digital | — |
| **Shannon** | Capacidad teórica | bit/s |
| **Nyquist** | Condición de muestreo | Hz |
| **Aliasing** | Error por muestreo insuficiente | — |
