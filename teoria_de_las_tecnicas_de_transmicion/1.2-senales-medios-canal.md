# 1.2 Señales, medios y canal de comunicación

## 🟢 Para comenzar

Ya sabemos que una información puede convertirse en datos. Ahora falta responder una pregunta fundamental: **¿cómo viajan esos datos físicamente?** La respuesta es mediante una señal.

Una señal puede viajar por cobre como una señal eléctrica, por fibra como luz y por radio como una onda electromagnética. Para entender su comportamiento necesitamos diferenciar señal, medio y canal, conceptos que suelen confundirse al comenzar a estudiar Telecomunicaciones.

Una señal puede ser eléctrica, óptica o electromagnética, dependiendo del medio y del sistema.

```text
⚡ Cable de cobre → señal eléctrica
🔦 Fibra óptica   → señal óptica
📡 Radio/Wi-Fi    → onda electromagnética
```

Una señal puede describirse usando varias características:

- 📈 amplitud;
- 🔄 frecuencia;
- 📐 fase;
- 📊 ancho de banda;
- ⚡ potencia.

Durante la transmisión puede sufrir alteraciones:

- 📉 atenuación;
- 📢 ruido;
- ⚡ interferencia;
- ⏱️ retardo.

### 📝 Ejemplo básico

Una señal sinusoidal puede representarse como:

```text
        /¯\      /¯\
       /   \    /   \
______/     \__/     \____
```

La forma de la onda permite estudiar parámetros que se explicarán en las siguientes secciones.

### 🛰️ Ejemplo aplicado

En un cable Ethernet, los datos digitales deben representarse mediante señales eléctricas. En fibra óptica, la información termina representándose mediante variaciones de luz. En un enlace inalámbrico, la información se transporta mediante ondas electromagnéticas.

### 🔗 Relación con la asignatura

La señal es el punto donde la información deja de ser solamente un dato abstracto y pasa a tener una representación física que puede medirse y analizarse.

### 🎯 Idea clave

> Una señal es la forma física que permite que la información viaje por un medio de comunicación.
## 🔍 ¿Qué puede cambiar en una señal?

Una señal puede variar en diferentes aspectos. Los más importantes para esta asignatura son:

```text
📈 amplitud
🔄 frecuencia
📐 fase
```

También puede describirse mediante potencia y ancho de banda.

### 🧩 Ejemplo de una señal sinusoidal

\[
x(t)=A\sin(2\pi ft+\phi)
\]

Esta expresión permite ver tres parámetros fundamentales:

- `A` representa la amplitud.
- `f` representa la frecuencia.
- `φ` representa la fase.

No siempre será necesario utilizar esta ecuación para resolver ejercicios, pero ayuda a comprender que una señal puede cambiar en más de una característica.

### 🛰️ Ejemplo aplicado

En una transmisión de radio, la señal física puede utilizar una portadora. Una técnica de modulación puede modificar su amplitud, frecuencia o fase para transportar información.

### ⚠️ Error frecuente

No todas las señales son ondas sinusoidales puras. Una señal cuadrada, un pulso o una señal de datos también pueden estudiarse utilizando las herramientas de esta unidad.

### 🎯 Para recordar

> Una señal es una función física medible que evoluciona en el tiempo y puede utilizar diferentes propiedades para transportar información.


Las señales pueden clasificarse, entre otras formas, como **analógicas** o **digitales**.
