# 🔗 5. Tipos de transmisión

---

## 5.1 Transmisión serie

## 🔗 Concepto

En una transmisión serie, los bits se envían uno después de otro.

```text
1 → 0 → 1 → 1 → 0 → 1
```

## 🧩 Desarrollo

Podemos representarlo:

```text
TX
 │
 ├── 1 ─────────────►
 ├── 0 ─────────────►
 ├── 1 ─────────────►
 ├── 1 ─────────────►
 └── 0 ─────────────►
                       RX
```

En una transmisión serie no necesitamos una línea física independiente para cada bit de una palabra transmitida simultáneamente.

### Ejemplos

- 🔌 UART.
- 🔌 USB.
- 🔗 Muchos enlaces de comunicación digital.

### 🎯 Idea clave

> Serie significa que los bits se transmiten secuencialmente.

---

## 5.2 Transmisión paralela

## 🔗 Concepto

En una transmisión paralela, varios bits se transmiten simultáneamente utilizando diferentes líneas.

```text
1 ─────────────►
0 ─────────────►
1 ─────────────►
1 ─────────────►
```

## 🧩 Desarrollo

Si queremos transmitir:

```text
1011
```

podemos imaginar:

```text
Línea 1 → 1
Línea 2 → 0
Línea 3 → 1
Línea 4 → 1
```

Todos los bits pueden enviarse al mismo tiempo.

Esto requiere más líneas físicas.

También puede generar problemas de sincronización entre líneas cuando aumentan las velocidades y distancias.

---

## 5.3 Comparación serie y paralelo

| Característica | Serie 🔗 | Paralelo 🔗 |
|---|---|---|
| Bits | Uno después de otro | Varios simultáneamente |
| Líneas | Menos | Más |
| Cableado | Más simple | Más complejo |
| Transferencia | Secuencial | Simultánea |
| Complejidad física | Generalmente menor | Generalmente mayor |

### 🎯 Forma fácil de recordarlo

```text
SERIE
1 → 0 → 1 → 1

PARALELO
1 ─────►
0 ─────►
1 ─────►
1 ─────►
```

## 5.4 Transmisión síncrona

## ⏱️ Concepto

Una transmisión síncrona utiliza una referencia temporal coordinada para que el transmisor y el receptor puedan interpretar correctamente el flujo de datos.

```text
CLOCK
_|¯|_|¯|_|¯|_|¯|_

DATA
_1___0___1___1___
```

## 🧩 Desarrollo

Podemos imaginar:

```text
Reloj:
tic   tic   tic   tic

Datos:
 1     0     1     1
```

El tiempo está coordinado entre los elementos de comunicación.

Esto es especialmente útil cuando existe un flujo organizado de datos.

---

## 5.5 Transmisión asíncrona

## ⏱️ Concepto

En una transmisión asíncrona no se mantiene un reloj compartido continuamente entre transmisor y receptor.

Los datos pueden utilizar bits de inicio y parada.

```text
┌───────┬──────────────┬───────┐
│ START │     DATOS    │ STOP  │
└───────┴──────────────┴───────┘
```

## 🧩 Desarrollo

El receptor utiliza esos elementos para identificar una unidad de información.

Podemos imaginar:

```text
START
  ↓
DATOS
  ↓
STOP
```

Esto permite determinar dónde comienza y termina la unidad transmitida.

Un ejemplo clásico de comunicación serie asíncrona es UART.

---

## 5.6 Comparación síncrona y asíncrona

| Característica | Síncrona ⏱️ | Asíncrona ⏱️ |
|---|---|---|
| Referencia temporal | Coordinada | No compartida continuamente |
| Datos | Flujo coordinado | Unidades delimitadas |
| Reloj | Referencia temporal compartida o coordinada | No se mantiene compartido continuamente |
| Estructura | Flujo de datos | Inicio + datos + parada |

### 🎯 Forma de recordarlo

```text
SÍNCRONA
⏱️ "Tenemos una referencia de tiempo coordinada"

ASÍNCRONA
📦 "Cada unidad indica dónde empieza y termina"
```
